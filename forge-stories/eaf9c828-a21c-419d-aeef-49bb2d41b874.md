# Show Characters in Post — Development Story

## Goal
Display a live character count beneath the post caption input on the **Save** screen so users always know how many characters they have typed.

---

## Tasks

### 1. Add character count text — `frontend/components/main/add/Save.js`

**Where:** Inside the `<View style={[{ marginBottom: 20, width: '100%' }]}>` that wraps `MentionsTextInput`, immediately after the `<MentionsTextInput … />` element.

**What to add:**
```jsx
<Text style={styles.charCount}>{caption.length} characters</Text>
```

`caption` is already tracked in state and updated via `onChangeText={setCaption}`, so the count updates automatically on every keystroke at zero cost.

### 2. Add `charCount` style — `frontend/components/main/add/Save.js` (local `StyleSheet`)

Append to the existing local `styles` object:
```js
charCount: {
    fontSize: 12,
    color: 'rgba(0,0,0,0.4)',
    textAlign: 'right',
    marginTop: 2,
},
```
This keeps the count unobtrusive, right-aligned under the input, using the same muted-grey colour pattern used elsewhere in the codebase (`text.grey`).

---

## Acceptance Criteria
1. Opening the **Save** screen shows `0 characters` under the caption field.
2. Typing updates the count in real time (e.g. "Hello" → `5 characters`).
3. Using an `@mention` autocomplete still updates the count correctly.
4. The rest of the Save screen (media preview, upload flow, Snackbar) is unaffected.
5. The count text is clearly readable but visually secondary to the input.
